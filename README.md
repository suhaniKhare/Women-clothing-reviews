## Women Clothing Reviews Analysis using Machine Learning

## Overview

This project focuses on analyzing the Women Clothing Reviews Dataset using Machine Learning techniques. 
The goal is to extract meaningful insights from customer reviews and build a predictive model to understand customer sentiment and behavior.

By leveraging data preprocessing, feature selection, and model training, this project demonstrates how machine learning can be applied to real-world problems 
such as e-commerce analytics and customer feedback systems.

## Objectives
1. Analyze customer reviews and ratings
2. Perform data cleaning and preprocessing
3. Identify important features affecting reviews
4. Build a predictive machine learning model
5. Evaluate model performance

## Dataset

The dataset contains customer reviews of women’s clothing, including:

1. Review Text
2. Rating
3. Age
4. Product Category
5. Recommendation Indicator
